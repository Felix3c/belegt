Amazon Bedrock in AWS European Sovereign Cloud

This topic describes the functionality of Amazon Bedrock in the AWS European Sovereign Cloud Region.

Amazon Bedrock is a fully managed service that makes it easy to use foundation models from third-party providers and Amazon.

How Amazon Bedrock differs

The following differences apply to Amazon Bedrock:

Model availability for all regions, including AWS European Sovereign Cloud, is available at Model support by AWS Region.

Feature support for all regions, including AWS European Sovereign Cloud, is available at Feature support by AWS Region.
