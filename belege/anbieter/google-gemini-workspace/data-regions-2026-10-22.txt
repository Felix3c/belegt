Google Workspace Data Regions
Stay organized with collections
Save and categorize content based on your preferences.
With Google Workspace Data Regions, you can configure specified Core Services
and Other Services to comply with Section 1 (Data Regions) of the
Google Workspace Service Specific Terms
to store specified Customer Data and (depending on the applicable version of
Data Regions) to process that data in a specific geographic location (the United
States or Europe).

Included features and capabilities
The specific features or capabilities included in each version of Data Regions
are described below.
Data Regions version
Specific features and capabilities included
Fundamental Data Regions
Set a single data at rest region policy for everyone in a customer's organization
Data Regions for Education
The same features and capabilities as Fundamental Data Regions, plus the following:
Set data at rest region policies for organizational units or groups
Basic data regions reports
Enterprise Data Regions
The same features and capabilities as Data Regions for Education, plus the following:
Set data region processing policies
Advanced settings for data regions
Assured Controls Data Regions
The same features and capabilities as Enterprise Data Regions, plus the following:
Advanced data regions reports
Policy compliance log events
Other editions, services, data types, and data states
Data Regions is not supported for Google Workspace editions, Core Services,
Other Services, data types, or data states that are not specifically identified
on this page. For example, Data Regions is not supported for Google Workspace
for Education Fundamentals, Gemini Notebook (formerly
NotebookLM), or logs or cached content.
Data Regions coverage for data processed in use depends on the applicable Data
Regions version. For example, Data Regions for Education does not cover data
processed in use.
Users of a Google Workspace edition that is not supported for Data Regions (for
example, Google Workspace for Education Fundamentals) or a Core
Service that is not supported for Data Regions (for example,
Gemini Notebook) aren't covered by Data Region policies even if a
Data Region policy has been applied to their organizational unit.
