Discover Frequently Asked Questions about On-Demand Inference What is an On-Demand Inference service? On-Demand Inference is Exoscale’s serverless Inference API, also commonly described as Model-as-a-Service (MaaS). It provides pay-per-token access to a curated catalog of AI models without requiring you to provision GPUs or operate model-serving infrastructure. Does On-Demand Inference support Zero Data Retention (ZDR)? Yes. Exoscale does not persist inference request payloads or model responses after processing, and prompt text itself is never stored in the cache. Only metadata required for usage reporting is retained, and customer prompts, inputs, and responses are not used to train, retrain, or fine-tune AI models. This guarantee covers the Exoscale inference service; customer applications and connected tools may have separate logging or retention behavior. How is On-Demand Inference different from Dedicated Inference? On-Demand Inference is designed for flexible, usage-based consumption (you pay per token) of a curated model catalog. Dedicated Inference is designed for customers who want to deploy and operate their own chosen model on managed, dedicated GPU-backed infrastructure. Can I choose from multiple model categories? Yes. On-Demand Inference currently provides models for chat completions and embeddings. The catalog can expand with additional models and categories during the Private Preview and beyond. Can I use my existing AI tools with On-Demand Inference? On-Demand Inference offers an OpenAI-compatible API. Tools that let you configure the API endpoint and credentials can connect without changing their core request format. See the Quick Start for currently supported requests and parameters. How does the token pricing work? Pricing is calculated based on the number and type of tokens processed. Input, output, and eligible cache-read tokens can have different rates. Cache-read pricing lowers the cost of eligible input tokens reused during a conversation, while prompt text itself is never stored in the cache. Cache-write support, including TTL configuration, is coming soon. See the technical documentation for current tentative pricing and cached-token details. Can I monitor and control On-Demand Inference usage? During the Private Preview, you can monitor On-Demand Inference usage in the Exoscale Portal. More granular controls, including limits per AI API key, are coming soon. Where will the On-Demand Inference solution run? During the Private Preview, On-Demand Inference is available in Vienna, Austria, in the AT-VIE-2 zone. For General Availability, Exoscale plans an SLA and availability in an EU location and a Swiss location. See the technical documentation for current location availability.
