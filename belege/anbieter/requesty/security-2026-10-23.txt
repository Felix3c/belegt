Questions security teams ask
Is my data encrypted?
Yes. All traffic is encrypted in transit with TLS 1.2 or higher, and all data at rest is encrypted with AES-256. Credentials and API keys are stored encrypted and never logged.
How does PII detection work?
Requesty scans prompts and responses for personal data and secrets before they reach the model provider or come back to you. Each scanner is set to report or mask, organization wide or per group. It covers names, emails, phone numbers, SSNs, card numbers, and credentials such as API keys and database passwords.
Can I block specific models or providers?
Yes. Administrators can restrict the organization, or a group, to an approved list of models. A call to anything else gets a clear 403, and every attempt is logged for audit.
Do you retain my prompts or completions?
On self serve plans, prompt and output logging is on by default and retained for up to 30 days in encrypted form within the EU. You can turn it off per API key at any time. Organization-wide zero data retention, under which no prompt or output content is persisted and our own caching is disabled, is enabled on written request. Audit logs record metadata (timestamp, user, model, token counts, cost) in every configuration.
Is Requesty SOC 2 compliant?
Our SOC 2 Type II programme is in progress. Current certification and audit status is published at trust.requesty.ai, and we make no representation of certification beyond what is stated there. We are GDPR compliant, provide a DPA on request, and support EU data residency in Frankfurt.
How are API keys protected?
API keys are hashed at rest and shown in full only once, at creation. Administrators can rotate or revoke a key and set spend limits, access lists and an IP allowlist per key. Service accounts let you issue scoped keys for CI and agents without exposing a person’s credentials.
Can we restrict API access to our own IP addresses?
Yes, on every plan. Set an IP allowlist for the organization with single addresses or CIDR ranges, and narrow it further on any key. Requests from any other address are refused at the gateway.
How do we know if an API key has leaked?
The API Keys security view shows which coding agents, apps and SDKs use each key, named from the User-Agent and X-Title headers they send. Four checks run over the last 30 days: a new tool on the key, a traffic spike, a key shared by four or more tools, and mostly unattributed traffic. A new tool and a spike together is flagged Critical. Expire the key in one click; it can be undone.
Does Requesty sync users and groups from our identity provider?
Yes, on Enterprise. SSO works with Entra ID, Okta and any SAML 2.0 or OIDC provider. With directory sync on, IdP groups stay in sync with Requesty groups of the same name, and deprovisioning a user deletes their API keys so access ends immediately.
