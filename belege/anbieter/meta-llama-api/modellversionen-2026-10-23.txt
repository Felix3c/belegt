What is the difference between the model versions?

Meta Model API offers several models that differ in size, context window, supported input types (such as text, images, or video), and specialized strengths like reasoning, coding, or multilingual output. Larger models generally produce higher-quality output but cost more per token.

For the full model lineup, context windows, and capabilities, see Models in the developer documentation.
