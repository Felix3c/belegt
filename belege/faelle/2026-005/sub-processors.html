Software as a Service
Web search and page fetching for the Opper web search tool (default engine). Receives search queries and URLs from customer requests; EU endpoints.

Auth0 (Okta)

Software as a Service
Customer authentication for the Opper platform (EU tenant): sign-up, login and session management.
Germany, Ireland
auth0.com

Datadog

Software as a Service
Monitoring of both production environments: infrastructure metrics, traces, access and application logs, request identifiers, IP addresses, and user and organization identifiers. Routine logging is designed to exclude prompts, responses and uploaded files.
Germany
datadoghq.com

Mixpanel

Software as a Service
Product analytics for the Opper platform: user and organization identifiers, name, email address, organization information, product usage events, and approximate location derived from IP address. Session recordings, heatmaps and automatic event capture are disabled.
EU/EEAAny member state
mixpanel.com

Sentry

Software as a Service
Error reporting for the Opper platform web app: exception details, stack traces, breadcrumbs, request routes, and user and organization identifiers. Request bodies and cookies are removed from error events; session replay and performance tracing are disabled.
Germany
sentry.io

Resend

Software as a Service
Transactional and product e-mail delivery: e-mail address, name, organization information, message content, and delivery and engagement metadata; also manages contact lists and subscriptions.
Ireland, United States
resend.com
