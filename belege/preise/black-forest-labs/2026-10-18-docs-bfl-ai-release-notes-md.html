It supports the same features: text to image, image editing, multi reference, and bounding boxes. Run it through the API, download the weights from Hugging Face, or load it in ComfyUI. ### Key Features * **Same request as FLUX 3 Image:** `prompt`, `images`, `aspect_ratio`, `resolution`, and the bounding box format are unchanged. A FLUX 3 Image request runs on Klein by switching the endpoint * **Two variants:** Klein (Distilled) runs 16 steps at CFG 1 for fast inference. Klein Base runs 50 steps at CFG 3.5 and is the model for fine-tuning and LoRA training * **Open weights:** both variants are on Hugging Face under the FLUX Kommunity License and run on consumer GPUs, down to an RTX 3090 * **Up to 4K output:** `resolution` from `768sq` to `4k`, with up to ten reference images per request * **LoRA training:** train on Klein Base with AI Toolkit (`arch: flux3`) or Diffusers. The trained LoRA also loads into Klein (Distilled) ### Pricing Per image, by `resolution`. Generate an image from a prompt, edit specific parts of an image, and combine up to ten references, all through one endpoint. ### Key Features * **Bounding boxes in the prompt:** place every element of a layout, such as a headline, a face in a crowd, or each panel of a grid. Add a JSON list of boxes to the end of `prompt`; there is no separate parameter * **Pixel-exact local edits:** mark the element to change and keep the rest of the image as it was. Recolor, replace, move, resize, or remove several elements in one request * **Up to ten references:** name each image by its position in the prompt to restyle an image or combine references into a new composition * **Up to 4K output:** `resolution` goes from `768sq` for fast previews to `4k` (about 16 megapixels), at 15 aspect ratios * **One endpoint:** the prompt decides whether to generate or edit. There is no `mode` field ### Pricing Per image, by `resolution`: | `resolution` | Price | | - | - | | `768sq` | \$0.041 | | `1k` | \$0.048 | | `2k` | \$0.100 | | `4k` | \$0.607 | ### Endpoint [FLUX 3 Image API reference](/api-reference/utility/generate-an-image-with-flux-3) Start with the [FLUX 3 Image overview](/flux_3/flux3_image_overview), see the box format in [FLUX 3 Image Editing](/flux_3/flux3_image_layout), or follow the [Bounding boxes](/flux_3/flux3_image_bounding_boxes) tutorial. ## FLUX 3 Video — 2K and 4K Output `resolution` on `POST /v1/flux-3-video` now takes `qhd` and `uhd` alongside `hd` and `fhd`, so a 2K or 4K clip comes back from a single request instead of a generation followed by a separate upscale call. ### Key Features * **`qhd`** — 2560 × 1440 at 16:9 * **`uhd`** — 3840 × 2176 at 16:9 * **Same generation, larger canvas** — every class above `hd` runs the same generation and differs only in the canvas the video upsampler renders, so the shot does not change with the resolution you pick * **Available on `draft_enhance` too** — commit a draft straight to 2K or 4K. Drafts themselves still render at `hd` ### Pricing Per second of output, in addition to the existing `hd` and `fhd` rates: | Mode | `qhd` | `uhd` | | - | - | - | | Text to Video (`t2v`) | \$0.40/s | \$0.80/s | | Image to Video (`i2v`) | \$0.40/s | \$0.80/s | | Video Continuation (`v2v`) | \$0.65/s | \$0.95/s | ### Endpoint `POST /v1/flux-3-video` Delivered dimensions for every aspect ratio are in the [FLUX 3 video documentation](/flux_3/flux3_video#resolution), and full rates on the [pricing page](/quick_start/pricing). ## Auto Top-Up for Credits You can now recharge your credit balance automatically. Send a clip of up to 20 seconds and get it back at up to 4K, with the original audio track preserved. ### Key Features * **1.5×–3× upscaling** — `upscale_factor` scales relative to the source resolution; the output keeps the source aspect ratio, capped at about 14.4 megapixels per frame * **Two modes** — `creativity: 0` (precise) preserves the source exactly and sharpens it, ideal for faces, products, and brand assets; `creativity: 1` (creative, default) restores and invents fine detail for generated footage, textures, and scenery * **Optional `prompt`** — describe the clip's content to steer the enhanced detail in creative mode * **Source limits** — up to 20 seconds, 50MB, and 2560 × 1440; rejected clips are not charged * **Pay for delivered output only** — \$0.07 (precise) / \$0.10 (creative) per megapixel-second ### Endpoint `POST /v1/flux-tools/video-upscale-v1` See the [FLUX Video Upscale documentation](/flux_tools/flux_video_upscale) to get started, and the [pricing page](/quick_start/pricing#flux-tools-video) for per-resolution rates. ## FLUX 3 — Video Continuation Duration Limit The maximum duration for video continuation (`v2v`) requests is now **15 seconds**.
