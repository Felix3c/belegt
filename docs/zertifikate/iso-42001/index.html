ISO/IEC 42001 (KI-Managementsystem): welche europäischen KI-Anbieter es nachweisen

Kurz: 6 von 33 geprüften Anbietern weisen ISO/IEC 42001 (KI-Managementsystem) mit verlinkter Primärquelle nach: Amazon Bedrock (AWS), Modell-Plattform (US), Anthropic Claude API (Claude Developer Platform) (US), Anthropic Claude Enterprise (Unterschiede zum Team-Plan in den Anmerkungen) (US), Nebius (Token Factory) (NL), OpenAI API (API Platform für Entwickler und Unternehmen) (US), OpenAI ChatGPT Enterprise (Unterschiede zu ChatGPT Business in den Anmerkungen) (US). 5 berufen sich darauf, ohne einen prüfbaren Nachweis zugänglich zu machen: Cohere (SaaS-Plattform und API) (CA), Google Gemini für Google Workspace (Gemini-App als Core Service und Gemini in Workspace), Unternehmensfassung (US), Google Vertex AI (heute Gemini Enterprise Agent Platform) mit Gemini-Modellen, Gemini API über Google Cloud für Unternehmen (US), Microsoft Azure OpenAI (Foundry Models sold by Azure in Microsoft Foundry), Unternehmens-API (US), Microsoft Copilot (früher Microsoft 365 Copilot), Unternehmensfassung (US). Bei 22 Anbietern haben wir keine belastbare Angabe dazu gefunden.
