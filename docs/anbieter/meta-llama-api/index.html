Meta Model API (früher Llama API)

Metas eigene Entwickler-Schnittstelle (llama.developer.meta.com leitet auf dev.meta.ai um) für die gehosteten Muse-Modelle; Llama-Modelle laufen dort laut Meta nicht. Zwei Stufen: Standard (kein Training, Meta als Auftragsverarbeiter) und Contributor (billiger, Inhalte gehen ins Training). Kein Rechenzentrumsort genannt; Null-Speicherung nur auf Antrag.

Hilfe-Artikel: „Zero Data Retention (ZDR) is available for qualified Meta Model API accounts.“ und „ZDR isn't part of standard usage and can't be turned on from the web UI.“ Wirkung: „your prompts and the model's responses are processed in real time and aren't stored by Meta after the response is returned, except where retention is required to comply with the law or to address misuse.“ Mit ZDR gesperrt (Anfragen werden abgelehnt): gespeicherte Antworten, Hintergrund-Anfragen, Datei-Uploads, Websuche, Contributor-Modelle. Auch mit ZDR bleiben markierte Inhalte: „Meta may retain the associated inputs and outputs for up to 2 years“. „ZDR support may vary by model.“ Gilt nicht über Drittplattformen: „Calls routed through third-party platforms follow that platform's data retention policy.“ Diese Zusage steht nur im Hilfe-Artikel, nicht in den Nutzungsbedingungen.
