Kein Training mit Kundendatenbelegt
Ja — Kundendaten werden nicht zum Training genutzt
DPA: 'EUrouter does not use Customer API Data to train, fine-tune or improve AI models' — standardmäßig ausgeschlossen. Ebenso in den AGB (General Terms and Conditions, 'Last updated: June 2026'): 'EUrouter shall not use Input Data for any purpose other than delivering the Service or use Input Data to train, fine-tune, or improve any AI Model.' Gilt für EUrouter selbst; für die nachgeschalteten Provider verweist das DPA auf deren eigene Position. Archivkopien web.archive.org/web/20261005042945 (DPA), 20261005043013 (AGB)
Quelle · geprüft 08.10.2026
Zero Data Retentionbelegt
Ja — keine Speicherung der Anfragen
Zero-Retention als Standard für Request-/Response-Inhalte; nur Metadaten (Timestamps, Token-Counts) für Abrechnung. DPA §10: 'By default, the Processor applies a zero-retention policy with respect to the content of API requests and responses.' AGB (Juni 2026): 'EUrouter applies a zero data retention policy to the content of API Requests and Outputs by default. Such content is not stored or used by EUrouter for any purpose beyond delivering the Service in real time.' Gilt für EUrouter selbst, nicht für den gewählten Provider; per Anfrage-Parameter max_retention_days lässt sich laut Doku auf Provider ohne Speicherung einschränken. Archivkopien web.archive.org/web/20261005042945 (DPA), 20261005043013 (AGB), 20261005043044 (Datenschutzerklärung). Laut Datenschutzerklärung (eurouter.ai/privacy, Version 1.2 vom 25.08.2026, geprüft 05.10.2026) API-Metadaten bis 12 Monate, Fehler- und Monitoringdaten bis 90 Tage, jeweils länger bei Sicherheits-, Abrechnungs- oder Rechtsgründen.

Vertrag

Zweckbindung über Training hinausnein
DPA (Last updated: May 2026, Abruf 08.10.2026), Annex 1 'Purpose(s)' nennt neben Routing und Rückgabe auch: 'measuring usage, calculating costs and supporting billing'; 'maintaining the security, availability, reliability and performance of the Services'; 'detecting and preventing abuse, fraud, misuse and security incidents'; 'providing technical or customer support at the Controller's request'. 'Nature of the Processing' ergänzt 'monitoring performance and reliability, detecting errors, preventing abuse, investigating security issues'. Die AGB (Juni 2026) sagen enger: 'EUrouter shall not use Input Data for any purpose other than delivering the Service' — für Inhalte gilt das, für Metadaten nennt das DPA die weiteren Zwecke. Kein Training, kein Verkauf ('does not use Customer API Data to train, fine-tune or improve AI models and does not sell Customer API Data').

Datenschutzerklärung (Version 1.2, Abruf 08.10.2026): 'We keep API metadata, such as timestamps, token counts and usage data, for up to 12 months, unless longer retention is necessary for security, billing, legal claims or compliance purposes.
